REST API (curl)

curl -s -X POST \ "https://litellm.ecouncil.ae/v1/audio/transcriptions" \ -H "Authorization: Bearer sk-05132025" \ -F "model=hamsa-stt" \ -F "file=@/path/to/audio.wav" \ -F "language=auto"

Replace /path/to/audio.wav with your audio file (PCM 16kHz 16-bit WAV). The endpoint returns JSON with text, gender, duration, and other Hamsa fields.
